What I Built

This project involves creating a single-page Learning Portfolio website using HTML and CSS.

The website consists of the following key sections:

  • web structure
  • styling
  • layout

When opening the website directly on my own computer, the client is the web browser, which reads and displays the HTML and CSS files stored on the computer. However, a web server is not involved because there is no server to receive and process the request.

How I Built It

  1. Design the website first by outlining the content structure and deciding what elements to include.
  2. Build the webpage structure using HTML, employing Semantic HTML appropriately such as header, main, section, and footer.
  3. Use CSS to manage the website layout such as typography, spacing, element sizes, and positioning to ensure aesthetic appeal and readability.

Learning is supported by the use of study materials, online research, and hands-on coding practice.

Reflection

One of the main challenges I encountered was positioning and sizing the elements as intended. Sometimes, after editing CSS, the result displayed on the website is not as expected. I therefore had to try different values and check the code step by step to find and fix the problems.
